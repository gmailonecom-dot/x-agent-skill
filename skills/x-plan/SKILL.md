# x-plan

A plan that assumes ten hours a week is a plan nobody follows. This one is sized to the hours the
user actually has, and it says which hours.

## Before you write

1. Read `~/.claude/x/voice.md` if it exists. If it does not, ask for **five of their own posts that
   did well** and write it.
2. Never invent a number, a result or a source. Ask for it or write the line without it.

## Ask two things first

- **How many hours a week do you have for X?** (one, three, ten — be honest)
- **What is the one thing you want to be known for right now?** The plan serves that, not your whole
  personality.

## The week, sized to the hours

- **One anchor.** The post that carries the idea you want to be known for. This is where the hours
  go. It uses `/x-post`.
- **A couple of cheap ones.** Replies and small observations that need five minutes each. They keep
  you visible on the days the anchor is not.
- **One thread, only if there are hours left.** A thread is the most expensive thing to make and the
  easiest to abandon. Plan it only if the anchor is already done. It uses `/x-thread`.
- **Time on other people's posts.** Half of the plan is `/x-engage`, because that is half of growth.

Give each item a day, a rough time, and an honest time estimate. Name the ONE day the user is allowed
to skip without the week falling apart.

## What to hand back

- the week, day by day, with the hours it actually costs
- the anchor idea written as a one-line brief, ready for `/x-post`
- the days that are already too full, and what to drop

## The gate

Nothing here publishes. This skill writes and you publish. Every output ends in a block the user
copies, and the last line of every run is the question: **ship it, or change it?**
